# Sayod 111 B2B & E-Commerce Intelligence MCP Server

Connect compatible MCP clients to three Sayod 111 engines hosted on Apify. Apify authentication and usage charges may apply.

## Tools

- [CommercePulse Pro](https://apify.com/sayod111/commercepulse-pro): e-commerce store analysis and product data.
- [B2B Revenue Intelligence](https://apify.com/sayod111/b2b-revenue-lead-enricher-mcp): company technology signals and public information.
- [B2B Hiring Intent ATS Scanner](https://apify.com/sayod111/b2b-hiring-intent-ats-mcp): public career-board data across seven ATS platforms.

## Remote MCP endpoint

```json
{
  "mcpServers": {
    "sayod111-intelligence": {
      "url": "https://mcp.apify.com/?tools=sayod111/commercepulse-pro,sayod111/b2b-revenue-lead-enricher-mcp,sayod111/b2b-hiring-intent-ats-mcp"
    }
  }
}
```

See [Apify MCP documentation](https://docs.apify.com/platform/integrations/mcp) for client setup and authentication.
